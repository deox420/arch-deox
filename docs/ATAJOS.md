# Atajos de teclado (kali-deox)

`SUPER` = tecla Windows. En cualquier momento: **`SUPER + F1`** muestra esta chuleta.

## Básicos
| Atajo | Qué hace |
|---|---|
| `SUPER + Enter` | Terminal (Kitty) |
| `SUPER + D` | Lanzador de apps (incluye todo el menú de herramientas de Kali) |
| `SUPER + E` | Archivos (Thunar) |
| `SUPER + B` | Navegador (Firefox ESR) |
| `SUPER + Q` | Cerrar ventana |
| `SUPER + L` | Bloquear pantalla |
| `SUPER + SHIFT + E` | Menú de apagado / reiniciar / salir |

## Ventanas y escritorios
| Atajo | Qué hace |
|---|---|
| `SUPER + flechas` | Mover el foco entre ventanas |
| `SUPER + SHIFT + flechas` | Mover la ventana |
| `SUPER + F` | Pantalla completa |
| `SUPER + V` | Ventana flotante ↔ mosaico |
| `SUPER + J` | Cambiar la división (vertical/horizontal) |
| `SUPER + 1…0` | Ir al escritorio 1…10 |
| `SUPER + SHIFT + 1…0` | Mandar la ventana al escritorio 1…10 |
| `SUPER + S` | Escritorio oculto (scratchpad) |
| `SUPER + ratón izq./der.` | Arrastrar / redimensionar |
| 3 dedos en el touchpad | Cambiar de escritorio |

## Utilidades
| Atajo | Qué hace |
|---|---|
| `Imprimir` | Captura de una zona (se abre en swappy para anotar) |
| `SHIFT + Imprimir` | Captura de pantalla completa |
| `SUPER + C` | Historial del portapapeles |
| `SUPER + T` | Cambiar tema de colores |
| `SUPER + SHIFT + R` | Recargar Hyprland |
| `SUPER + SHIFT + W` | Reiniciar la barra |

## En la terminal
| Comando | Qué hace |
|---|---|
| `deox-objetivo 10.10.11.42` | Fija la máquina objetivo: sale en la barra y en `$OBJETIVO` |
| `deox-vpn-ip` | Tu IP de la VPN (tun0/wg0) = LHOST |
| `caja lame` | Crea `~/cajas/lame/{nmap,loot,exploits,notas.md}` y entra |
| `servir` | Servidor web en el puerto 8000 (pasar ficheros) |
| `deox-auditar` | ¿Tengo paquetes con vulnerabilidades conocidas? |
| `deox-tema --lista` | Temas disponibles |
| `actualizar` | `sudo apt update && sudo apt full-upgrade` |

Kitty: `Ctrl+Shift+Enter` divide la ventana, `Ctrl+Shift+T` nueva pestaña, seleccionar = copiar.
